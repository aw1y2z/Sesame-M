# 配置项说明（按模块）

> 本文件由 `docs/tools/gen_fields.ps1` 从源码中的字段声明自动生成，顺序与源码声明一致（与配置页显示顺序基本一致）。
> 修改源码配置项后重新生成：`powershell -ExecutionPolicy Bypass -File docs/tools/gen_fields.ps1`
> 分组与模型顺序取自 `ModelGroup` / `ModelOrder`。
>
> - 「默认 / 范围」里的枚举常量（如 `DonationType.ZERO`）是源码里的取值名，对应配置页下拉框的选项。
> - 「依赖」列表示该项依赖的开关，父开关关闭时该项不生效。
> - 同一模型内字段顺序与配置页一致；不同分组的模型排列顺序由 `ModelOrder` 决定。
